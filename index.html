FEATURED PROJECT

FITNESS LOG
운동 기록 웹 서비스

운동 기록을 쉽고 체계적으로 관리할 수 있도록 제작한 대표 웹 프로젝트입니다.

  • 운동 기록 입력

    운동 부위와 종목을 선택하고 날짜, 중량, 횟수를 입력해 운동 내용을 저장할 수 있도록 구현했습니다.

  • 기록 조회 및 관리

    저장된 기록을 날짜별로 확인하고, 기존 기록을 수정하거나 삭제할 수 있도록 구성했습니다.

  • 성장 통계

    종목별 최고 중량과 운동 변화를 확인할 수 있도록 기록 정보를 통계 형태로 표현했습니다.

  • 통합 웹 서비스

    운동 기록뿐 아니라 운동 팁, 게시판, 문의하기 기능을 하나의 서비스 흐름 안에 구성했습니다.

HTML · CSS · JavaScript · LocalStorage

LEARNING PROJECTS

수업과 과제를 통해 새로운 기능과 기술 활용 방법을 익힌 학습 프로젝트입니다.

  • LIFE QUEST

    해야 할 일을 퀘스트처럼 관리하는 게임형 투두리스트입니다. 등록, 조회, 수정, 삭제와 완료 처리 기능을 구현하고 Supabase를 연동해 데이터 저장 방식을 학습했습니다.

    HTML · CSS · JavaScript · Supabase

  • OMDb MOVIE SEARCH

    OMDb API를 활용해 영화 제목을 검색하고 결과를 출력하는 React 학습 프로젝트입니다. 검색창과 결과 영역을 컴포넌트로 분리하며 API 활용 방법을 학습했습니다.

    React · JavaScript · styled-components · OMDb API

SKILLS & STRENGTHS

새로운 기술을 배우고 직접 구현하며, 웹 서비스가 작동하는 구조를 이해하기 위해 노력하고 있습니다.

  • HTML / CSS

    웹 페이지의 구조를 작성하고, 레이아웃과 반응형 화면을 구현합니다.

  • JavaScript

    DOM 조작, 이벤트 처리, LocalStorage와 API 연동을 활용해 동작하는 기능을 구현합니다.

    컴포넌트 분리와 상태 관리의 기초를 학습하며 재사용 가능한 화면 구조를 만드는 연습을 하고 있습니다.

  • Spring

    Java와 Spring MVC를 기반으로 컨트롤러와 요청 처리 구조를 학습하고 있습니다.

    Supabase를 활용해 데이터를 저장하고 CRUD 기능을 연결하는 과정을 경험했습니다.

  • Collaboration

    Git과 GitHub의 브랜치, 커밋, Push, Pull Request 과정을 활용해 협업 방식을 학습했습니다.
